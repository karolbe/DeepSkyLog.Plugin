# DeepSkyLog NINA Plugin - Changelog

## 1.0.0.1

### Added
- Browser-based authentication with DeepSkyLog accounts
- Automatic token validation and session management
- Location selector from user's DeepSkyLog profile
- Equipment selector from user's DeepSkyLog profile
- Comprehensive metadata sync including:
  - Image quality metrics (HFR, FWHM, stars, ADU)
  - Guiding performance (RMS values)
  - Weather conditions
  - Focuser and rotator positions
  - Target coordinates and equipment details

### Changed
- Authentication now uses secure browser-based OAuth flow instead of manual token entry
